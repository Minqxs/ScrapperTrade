# AI and Research Architecture

AI providers are adapters: Manual ChatGPT Mode, local provider, and optional OpenAI API. The system remains usable without API billing. Credentials are user-supplied secrets outside Git.

Research consumes provenance-bearing source chunks, market/trade evidence, and immutable experiment configuration. Provider output is untrusted data: parse into a versioned strategy specification, validate schema and semantics, reject ambiguity/conflict, check indicator and risk compatibility, and run the full validation loop. No `eval`, generated C#/MQL5 deployment, execution tool, hard-policy mutation, instrument allowance, emergency unlock, or self-promotion exists in this boundary.

Every hypothesis links to exact source material and extraction/provider/version metadata. Derived challengers preserve lineage. Champion changes require governed evidence and user-controlled production boundaries; research may recommend but not authorize.
